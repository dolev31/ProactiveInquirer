Ask whether the current draft would change if you learned one more fact. If the evidence
above already resolves every need the task requires, sufficiency holds and refinement

HOW TO PROPOSE THE NEXT QUERY
When sufficiency fails, name the entity your query is about explicitly, because the
retriever matches text and cannot resolve a pronoun. Cite in parent_uids the units whose
